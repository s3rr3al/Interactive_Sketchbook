Process Reflection

The universal styles, header, navigation, section, and article are the elements of this website that each have a flex box. Each of these elements became flex items on the webpage. Once the header was given a flex box, it became centered and more aesthetically pleasing on the web page. The three-column layout was applied by adjusting the flex direction to column. Adjusting the width of the columns helped improve reading legibility of the content within each column. Adjusting the pixel size of each image to be the same helped create more cohesion between how they align with their body copy and bringing more visual unity on the webpage.

In resizing the browser window, the images along with their body copy resized with the browser adjusting, keeping legibility as it became smaller and enlarged. Troubleshooting the placement of the navigation menu was most confusing. I didn’t realize that typing center in the align items section would help center the nav menu, but now it makes sense. After doing this exercise, I’m starting to see how utilizing a flexbox will come in use when designing my interactive sketchbook. I think using align items in the specific sections where I want to control item alignment is really handy, when considering a cohesive webpage.
