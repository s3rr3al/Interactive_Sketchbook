Box Model Process Reflection

During the process of creating the box model. I was confused about the difference between margin and padding. After reviewing the site that we viewed during the lecture, https://jwoakley.github.io/boxModelAndInspector/ , I was able to understand visually what both are. Instruction number 3 in the list under the Padding section on the site, distinctly reads “the padding is the space between the content and the border” and instruction number two in the Margins section reads “margins are the spaces between elements”. The word explanation was helpful, but the visual examples provided on the site helped solidify my understanding.

The most challenging aspect of this process would have to be changing the display function of the bottom section (make me stack please). This stumped me for a while, til I went back and viewed the lecture site again, taking my time, reading each section to fully understand what the tasks were asking for. Using the inspect page as a way to double-check my coding was helpful, especially the visual diagram of the margins for the specific sections. I found the link to the source code in the website console to be extremely helpful with maintaining work flow efficiency, opposed to having to go back and forth between VScode and website browser windows.
